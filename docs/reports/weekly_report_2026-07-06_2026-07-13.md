# 周报：2026.07.06 - 2026.07.13

## 本周主线

本周工作的核心是将前期形成的 Visual Element Memory pipeline，进一步整理为一套面向论文投稿的清晰方法体系与实验框架。经过讨论，我们将论文方向暂定为：

> **Retrieval-Augmented Multimodal Prompting for Consistent Long-Form Video Generation**

这一表述将项目从传统“长视频记忆”叙事推进到更清晰的 RAG-style 视觉参考构建叙事：系统不是简单把历史帧作为记忆输入模型，而是动态维护可检索的视觉证据库，根据当前 shot 的生成目标选择互补参考帧，并将文本、图像和视频参考组织成具有明确指代关系的多模态 prompt，从而提升长视频跨镜头一致性。

## 主要进展

### 1. 明确论文方法定位

本周完成了方法主线的重新梳理。当前方法由三部分构成：

1. **动态视觉证据库构建**：维护文本侧视觉元素集合与状态表，并通过 VLM 标注生成后关键帧，形成候选关键帧库。
2. **目标覆盖式参考检索**：根据当前 shot 中应参考、应排除、可选和新出现的视觉元素，从历史关键帧中选择高质量、互补、低干扰的参考帧。
3. **可解释多模态 prompt 组织**：将选中的参考图、近端视频、元素状态和明确指代说明组织进 Seedance prompt，使模型知道应参考哪些图中的哪些实体，以及应避免引入哪些历史元素。

这一框架与 RAG 的对应关系较清楚：视觉元素集合与关键帧库相当于知识库，当前 shot prompt 相当于 query，覆盖式选帧是 retrieval，带指代的 prompt 是 grounded generation。

### 3. 建立 EntityBench 评测主线

本周将 EntityBench 确定为当前主要定量 benchmark。我们选取了一个 1/10 子集：

- Easy: 8 episodes
- Medium: 4 episodes
- Hard: 2 episodes
- 合计 14 episodes / 243 shots

当前 `Ours current 14` 已完成评测。初步结果显示，方法在 Pillar 3 跨镜头实体一致性上表现较突出：

- CS Face: 0.8151
- CS Object: 0.8830
- CS Boundary: 0.8004
- LLM Face Acc: 0.9001
- LLM Object Acc: 0.9506
- LLM Scene Acc: 0.9833

这与我们的方法假设一致：显式维护视觉元素、用 VLM 标注历史关键帧、再进行目标覆盖式参考检索，有助于提升跨 shot 的角色、物体和场景一致性。

需要注意的是，目前与 EntityBench 官方 baseline 的对比并非严格同分布。我们的实验使用子集、动画风格约束、Seedance 生成和 Seed2.1 Turbo judge，因此官方全量结果只能作为方向性参考。正式论文结论仍需依赖同 split、同设置下的消融实验。

## 阶段性认识

1. **RAG-style multimodal prompting 是当前最合适的论文叙事**  
   它能自然串联视觉元素集合、VLM 标注关键帧库、覆盖式选帧和指代式 prompt，也能清楚地区分我们与传统 memory buffer 方法的差异。

2. **当前结果支持跨镜头一致性方向，但仍需严格消融**  
   EntityBench 初步结果较好，尤其是 Pillar 3；但正式 claim 应建立在同 split 的 Prompt-only / No-reference / Top-K / Greedy / Full 方法对照上。

3. **方法亮点应聚焦在“可解释参考构建”**  
   每张参考帧为什么被选中、覆盖哪些元素、可能引入哪些干扰、如何写入 prompt，是我们区别于黑盒检索或简单记忆方法的重要优势。

4. **实验写作需要谨慎处理 baseline**  
   目前官方 baseline 不能直接作为严格横向比较，只能用于定位和趋势参考。论文主表应以同设置消融为核心。

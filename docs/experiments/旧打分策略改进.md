问题:
有时因为新shot剧本更换了场景与任务，此时不会选中任何参考帧。但这会导致新生成的视频风格可能发生突变，带来不一致性。首先，为什么会存在选中0个历史关键帧的情况?


旧打分策略:

当前 Visual Element Memory 的历史关键帧选择分两层：**单帧打分公式**和**多帧选择策略**。

**1. 单帧得分公式**

对候选关键帧中每个被 VLM 标注出的元素，若该元素存在于当前 Visual Plan 的已有元素状态表中，则加入得分。

总分可以理解为：

```text
frame_score = Σ element_score
```

其中每个元素：

```text
element_score =
    state_weight
  × type_weight
  × visibility_quality
  × reference_quality_weight
```

各项含义：

- `state_weight`
  - `should_reference` 且尚未覆盖：`reference_uncovered_weight = 1.0`
  - `should_reference` 且已覆盖：`reference_covered_weight = 0.2`
  - `optional_or_uncertain`：`optional_weight = 0.1`
  - `should_exclude`：`exclude_weight = -0.1`

- `type_weight`
  - character：`3.0`
  - scene：`2.0`
  - object：`1.5`

- `visibility_quality`
  - 由元素框大小、清晰度等内部函数 `_visibility_quality(...)` 计算。

- `reference_quality_weight`
  - full：`1.0`
  - partial：`0.2`
  - weak：`0.1`
  - 缺失时按 full 处理。

注意：当前只有 `reference_quality == "full"` 的 `should_reference` 元素才会计入 `newly_covered_element_ids`。也就是说 partial/weak 即使加分，也不算真正 covered。

**2. 贪心选择策略**

当前默认模式是：

```text
selection_mode = greedy_coverage
max_retrieved_frames = 4
sink_frame_count = 0
```

选择过程：

```text
selected = []
covered = set()
required_ids = 当前 Visual Plan 中所有 should_reference 元素 id
remaining = 所有历史关键帧 annotation

while len(selected) < max_retrieved and remaining 非空:
    best_score = 0.0
    best = None

    for each candidate in remaining:
        score = score_frame(candidate, covered)
        if score > best_score:
            best = candidate

    if best is None:
        break

    selected.append(best)
    covered.update(best.newly_covered_element_ids)
    remaining.remove(best)

    if selection_mode == greedy_coverage and required_ids 非空 and covered >= required_ids:
        break
```

所以关键点是：

- 只有 `score > 0` 的帧才可能被选中。
- 如果所有候选帧分数都 `<= 0`，则直接选 0 张。
- 每选中一张后，会更新 `covered`。
- 对已经 covered 的 `should_reference` 元素，后续帧得分会从 `1.0` 降到 `0.2`，鼓励覆盖新元素。
- 如果所有 required `should_reference` 元素都已被 full-quality 覆盖，则提前停止，不一定选满 4 张。

**3. Static top-k 模式**

如果切到 `static_top_k`，当前差别主要是：

- 已覆盖元素不会使用 `reference_covered_weight` 降权；
- 不会因为 `covered >= required_ids` 提前停止；
- 但仍然使用 `best_score = 0.0` 和 `score > 0` 才选。

所以 static top-k 也可能选 0 张，只是它更像按原始分数取正分 top-k。

**4. 当前问题的根源**

当前策略把两个判断混在一起了：

```text
这张图是否值得作为参考？
这张图是否覆盖了必须参考的元素？
```

由于 `score > 0` 是硬门槛，一张图即使覆盖了唯一的 `should_reference` 元素，也可能因为同时包含一些 `should_exclude` 元素而总分为负，从而完全不被选中。

改进建议:
不妨先这样
1.首先，令best_score = -inf而不是0，每轮循环还是要选出一个best，即使是负分或0。
但    if selection_mode == greedy_coverage and required_ids 非空 and covered >= required_ids:
        break
仍然保留。
这样至少能保证当存在历史帧时不会空选，至少有视觉风格参考。
2.其次，如果一张选中的帧没有cover任何需参考元素，则在“Reference guidance”中追加一句固定提示词：本张参考图中可能不含任何新视频所需的视觉元素，请将其作为视觉风格参考。
